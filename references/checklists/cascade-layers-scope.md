# cascade-layers-scope checklist (LAYER)
Covers `src/rules/layer.rs`, `src/rules/scope.rs`, `src/rules/import.rs`, the layer passes of `src/rules/mod.rs` (`:615-750`, `:986-1044`), the `@import`/`@layer`/`@scope` arms and the import state machine of `src/parser.rs` (`:152-159`, `:304-416`, `:447`, `:661-713`), and CSS-wide keywords. Facts, INV-LAY/IMP/SCO/CAS ids, master defects D1-D15: `references/spec/cascade-conditional.md` §1-4.
Top failure modes: (1) layer order changed by merging or hoisting (aedf6b6 → #974, fixed by 32aecd9 on master only); (2) `&` and prelude semantics inside `@scope` (#1189, #1165, D4, D5); (3) `@import` placement or conditions lost (D10, bundler F4, #1074).
`[open …]` in a verify line = master already fails: answer FAIL only if head is worse than base, extends the defect to new inputs, or claims a fix its probe does not confirm; a real fix is PASS (credit via A2). `[guard …]` = master passes; a regression there is a FAIL.
