# Checklist: text (prefix TEXT)
Covers `src/properties/text.rs` (TextDecorationHandler for text-decoration*, text-emphasis* and `text-align: start|end`; TextShadow; Spacing; WhiteSpace; TextTransform), the text members of `src/properties/prefix_handler.rs` (FallbackHandler: text-shadow; PrefixHandler: tab-size, hyphens, text-align-last, text-decoration-skip-ink, text-overflow, text-size-adjust) and `src/properties/mod.rs:1484-1514`. Spec, invariants (INV-TEXT-*) and master status: `references/spec/fonts-text.md` §1, §3.
Top failure modes: (1) prefixed copies duplicated, dropped or wrong per target (#872, #934, #1153); (2) shorthand serializers and typed parsers that lose a component or accept browser-invalid values, deleting the earlier declaration (`text-decoration:none red` → `none`, `none underline`, text-shadow spread); (3) panics in color fallback generation (text-shadow + `currentColor`).
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). Probe ids are curated `corpus/probes/<area>/` ids.
