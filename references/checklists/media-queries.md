# media-queries checklist (MQ)
Covers `src/media_query.rs` (its `QueryFeature`/`QueryCondition` code is shared with `@container`), `src/rules/media.rs`, `src/rules/custom_media.rs`, custom-media compilation in `src/stylesheet.rs:230-244`, the `@media` merges in `src/rules/mod.rs` and `MediaList::and` as used by `src/bundler.rs:490`. Facts, INV-MQ ids, defects D1/D2/D11-D15: `references/spec/cascade-conditional.md` §7, lowering §11.
Top failure modes: (1) range lowering that is inexact or unparsable for the targets (#228, #320, #1105, #1361); (2) negation or always-true lists printed with the wrong meaning (#152, D1, D2, D13); (3) invalid queries rewritten into valid ones (#1366, D12).
`[open …]` in a verify line = master already fails: answer FAIL only if head is worse than base, extends the defect to new inputs, or claims a fix its probe does not confirm; a real fix is PASS (credit via A2). `[guard …]` = master passes; a regression there is a FAIL.
