# Checklist: font (prefix FONT)
Covers `src/properties/font.rs` (FontHandler, `FamilyName`, system-ui stack), `src/rules/font_face.rs`, `src/rules/font_feature_values.rs`, `src/rules/font_palette_values.rs`, the `FontFeatureValues`/`FontPaletteValues` arms of `src/rules/mod.rs` (`:938-961`) and the font rows of `src/properties/mod.rs:1440-1449`. Spec, invariants (INV-FONT-*) and master status: `references/spec/fonts-text.md` §1-2.
Top failure modes: (1) font-* longhands reordered across or folded into `font`, which resets them (#1207, #1234; #1084/#572 are the same class for transition/animation); (2) family names unquoted or deduped so they no longer mean the same family (#120, #1054, #1221, EM-70); (3) typed parsers that accept browser-invalid values or print an invalid `font` (#1140), deleting the valid declaration before them.
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). Probe ids are curated `corpus/probes/<area>/` ids.
