# Checklist: display-layout (prefix DISPLAY)
Covers `src/properties/display.rs` (DisplayHandler, `DisplayPair` parsing, prefixed display values), `position.rs` (PositionHandler, `-webkit-sticky`), `overflow.rs` (OverflowHandler, text-overflow typing), `contain.rs` (container-type/-name), the typed-but-unowned `visibility` and `z-index`, the passthrough float/clear/contain/content-visibility/columns/break-*, and the `direction`/`unicode-bidi` buffering in `src/declaration.rs:646-657`, `:695-701`. Spec, invariants (INV-DISP-*, INV-POS-*, INV-OVF-*) and master status: `references/spec/layout.md` §5-7. `-webkit-box` 2009 flexbox values also load `flex-grid-align.md`.
Top failure modes: (1) finalize-time handlers reorder against `var()` or unowned sub-properties (#1225, N8 `overflow-inline`, `position-anchor`); (2) prefixed `display` values override a working `display:flex`, in one rule or across rules (#1291); (3) fallbacks dropped because a handler has no compat check (`overflow: clip`) or a grammar is too loose (`list-item list-item`).
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). Probe ids are curated `corpus/probes/<area>/` ids. The oracle cannot see `position` resetting `position-anchor` (no engine does yet): use output assertions there.
