# Checklist: ui-misc (prefix UI)
Covers `src/properties/ui.rs` (cursor, caret*, user-select, accent-color, appearance, resize, color-scheme and ColorSchemeHandler, print-color-adjust), `list.rs` (list-style*, ListStyleHandler), `svg.rs` (fill, stroke, markers, rendering keywords), their FallbackHandler (fill, stroke, caret-color, caret) and PrefixHandler (user-select, appearance, print-color-adjust) entries in `prefix_handler.rs`, the matching rows of `src/prefixes.rs`, and the passthrough counter-*, content, quotes, object-fit, object-position. outline belongs to `border-outline.md`. Spec, invariants (INV-UI-003, INV-LISTS-*, INV-CONTENT-001) and master status: `references/spec/layout.md` §9; color-scheme lowering also `references/spec/color.md` C12-C13.
Top failure modes: (1) FallbackHandler/PrefixHandler write-back reorders the cascade or overrides an author's per-vendor value (#1362, #977, class C); (2) invalid, empty or newer-syntax values replace a valid fallback (`caret-color:`, `fill`, `caret:`, `list-style:`); (3) shorthand and keyword serialization that changes meaning (`list-style: none` #890, named-like-position types, `color-scheme` order and custom idents #1152).
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). Probe ids are curated `corpus/probes/<area>/` ids. Oracle blind spots: no engine implements the `caret` shorthand (BCD: caret-shape Chrome 144+, caret-animation Chrome 140+ only), and WebKit computes `user-select` and `-webkit-user-select` independently, so an added prefix reads `different` there (O9).
