# Checklist: flex-grid-align (prefix LAYOUT)
Covers `src/properties/flex.rs` (FlexHandler: flex*, order, 2009 `-webkit-box-*`/`-moz-box-*` and 2012 `-ms-flex*` lowering), `src/properties/align.rs` (AlignHandler: align/justify/place, gaps, legacy box-pack/-align), `src/properties/grid.rs` (GridHandler: track lists, repeat(), areas, line names, placement, `grid`/`grid-template` folding) and `values/ident.rs` (`CustomIdent` for line names). Spec, invariants (INV-FLEX-*, INV-ALIGN-*, INV-GAP-*, INV-GRID-*) and master status: `references/spec/layout.md` §2-4, §11.
Top failure modes: (1) shorthand serializers that omit or misplace components (`place-*` #1182, grid folding #1130/#1096/#1132, line-name shift, pretty `grid-template`); (2) loose grammars that type invalid or empty values and delete the valid fallback (repeat(), auto-repeat, `span`, areas, `flex:`; Class A, 42+10+8 WPT pair cases); (3) legacy flexbox handling (`-webkit-box-*` cleared, `order` off by one, `gap` merged without a compat gate, `grid-gap` reordered).
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). Probe ids are curated `corpus/probes/<area>/` ids. A correct 2009 lowering adds standalone legacy properties that a reference engine can read as `different` (`spec/layout.md` §11): decide those with output assertions and the 2009 WD.
