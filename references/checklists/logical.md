Spec, invariants (INV-LOGICAL-*) and master status: `references/spec/fonts-text.md` §4.
Top failure modes: (1) generated `:dir()`/`:lang()` rules lost or attached to the wrong selector around nested rules (#1023, #1049, #1246); (2) cascade changes from moving declarations into separate, more specific, never-`!important` rules (#1179, #1018, N5); (3) values the lowering cannot see or maps wrongly (var() shorthands #927/#1070 and PR #1227, horizontal-tb and language heuristics, `inline-size` → `height` in transitions).
Answer FAIL only when head introduces or widens a violation; an `open:` or "by design" defect that base already has is PASS with an unchanged case as evidence, and a fix is credited (A2). Lowering needs targets: N/A needs evidence that no target lacks the Logical* feature. The oracle page is `<html lang="en">` without `dir` (`oracle/engine-runner.cjs:22`): RTL needs a probe `dom:` line.
