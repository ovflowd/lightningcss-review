# transition-animation checklist (ANIM)

Covers `src/properties/transition.rs` (`Transition` parse :23-110, `TransitionHandler` :158-381, `merge_properties` :383-398, `expand_properties` :400-470, logical names :493-497, `ViewTransitionName`), `src/properties/animation.rs` (`Animation::to_css` :662-711, `AnimationRange` :379-582, timelines :182-377, `AnimationHandler` :726-1077), `src/values/easing.rs`, `src/rules/keyframes.rs`, `@keyframes` replacement in `rules/mod.rs:626-666`, `@starting-style`, `@view-transition` (`rules/view_transition.rs`), view-transition pseudo-elements in `selector.rs`, the `AnimationTimelineShorthand` compat key (`compat.rs:3513`, `scripts/build-prefixes.js:337`) and the animation/transition prefix data (`prefixes.rs:258-337`). Spec: `references/spec/anim-transforms.md` §2-§6, §8-§9 (INV-TRN-001..006, INV-ANI-001..015, INV-EAS-001..004, INV-SDA-001..003, INV-VT-001..006).
Top failure modes: parallel lists misaligned so a property gets another's timing (#850, ANI-1); shorthands that engines reject or read differently (timeline folded #1115/#1283/#1342/#1369, `none` name drops components #337/#1095, #1226, #1012, #1214, ANI-2); reset-only longhands moved before the buffered shorthand (#1084, #1009, RM-4); `@keyframes` deleted or resolved to the wrong rule (#1103, #786, N2/N3, ANI-3).
Items describe head output. A `known: open-issue#N` or `open-bug` probe that is `still-different` on base and head does not FAIL an item unless the PR claims that bug. The oracle compares computed values at rest (L5): every timing or keyframe rewrite needs a sampling probe (`animation: k 1s linear -0.5s paused`, or `@starting-style` + `transition: … 1000s step-end`).
