# Checklist: box-model-size (prefix BOX)
Covers `src/properties/size.rs` (SizeHandler: width/height/min-*/max-*, logical sizes, `SizeFallback` sizing-keyword ladders, aspect-ratio, box-sizing), `src/properties/margin_padding.rs` (`side_handler!`: margin, padding, scroll-margin, scroll-padding, inset), the inset part of `position.rs`, `src/values/length.rs` (unitless numbers) and the box-sizing entry of `prefix_handler.rs`. Spec, invariants (INV-SIZE-*, INV-POS-002, INV-SNAP-001) and master status: `references/spec/layout.md` §6, §8; logical lowering is `logical.md`.
Top failure modes: (1) buffered sizes/sides reordered against Unparsed, unknown or alias declarations (#805/#547/#572, v1.21.0-v1.27.0; INV-SIZE-008); (2) invalid values typed and deleting the valid fallback (unitless px #1199/#682, scroll-margin `%`/`auto`, negative values #1000); (3) sizing-keyword and unit fallbacks lost or crashing per target (#826, #630, #1371, Opera dvh, `inset` gate).
Answer FAIL only when head introduces or widens a violation; an `open:` defect that base already has is PASS with an unchanged case as evidence, and a PR that fixes one is credited (A2). `by design:` = maintainer decision, not a defect. Probe ids are curated `corpus/probes/<area>/` ids. Fallback probes need targets: `browsers: None` treats every feature as supported (`targets.rs:226-228`).
