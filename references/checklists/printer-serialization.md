# printer-serialization checklist (PRINT)
Covers `src/printer.rs`, `src/serialization.rs`, `src/values/string.rs`, printing in `src/macros.rs`, every `ToCss` impl a PR changes, and the number, identifier and string serializers shared with values-numeric and custom-properties. Spec: `references/spec/syntax-values.md` §2 (anchor keys in §0).
Top failure modes: output that no longer re-parses to the same tokens or rules (missing `;` after nested declarations #989/#1002/#1003, merged tokens, raw identifiers EM-04); shortening that changes meaning (font-family quoting #1054, `border-image:none` -> empty #1146, keyword-named strings #267); whitespace changes that break idempotency or grow output (#1141, #1378).
`[open #N]` / `master FAILS` marks a pre-existing bug: answer FAIL only if head is worse than base, extends it to new inputs, or claims the fix while the probe still fails.

- [PRINT-01] (BLOCKER) Minified output re-parses to the same rules and declarations: every rule kind printed without braces or with its last `;` omitted is tested followed by another declaration and another rule, and re-minifying the output changes nothing (regression 6c465c1 v1.30.0: NestedDeclarations printed `margin:autodiv &{…}` #989/#1002/#1003/#1078, fixed by 9e04c01; stray separators #138 7bc3171, 1f66776).
  verify: R2; T3; probes nesting/nested-declarations-semicolon-2, nesting/nested-declarations-semicolon; mutation nest.
- [PRINT-02] (BLOCKER) Adjacent tokens that would re-tokenize differently keep a separator in every serializer (SYN#serialization table): ident before ident/function/number, number before number (`2e3` `.4`), dimension before ident, `/` before `*`, explicit `+` signs, and a unit starting with `e` plus a digit escaped as `\65 ` (master FAILS: token lists at src/properties/custom.rs:541-546 and :898-902; cssparser 0.37 serializer.rs:103-112 escapes only `e`/`e-` units, so `1e\32` prints `1e2`; `0\65` for unit `e` is correct, #939; `u + a` -> `u+a` is fine in current engines, #289/EM-12).
  verify: probes printer-serialization/token-number-number-boundary, printer-serialization/token-number-type-flag-kept, printer-serialization/dimension-unit-e-digit-not-exponent, printer-serialization/comment-dimension-function, custom-properties/plus-sign-token-boundary; R2.
- [PRINT-03] (MAJOR) Serializer shortcuts round-trip exactly: a string is unquoted into identifiers only when the identifier sequence re-parses to the same value (whitespace runs, leading and trailing spaces, generic and CSS-wide first words, `revert-rule`), and strings that look like keywords stay quoted (font-family #1054 fixed by #1064, which merged without compiling until 4e6492b and still loses leading/trailing spaces; #120; keyframes names #267/#287; master FAILS for `"revert-rule"`, EM).
  verify: probes font/family-consecutive-spaces, font/generic-family-name-quoted, font/font-family-generic-first-word, font/font-family-revert-rule-stays-quoted, transition-animation/keyframes-string-name-revert-rule.
- [PRINT-04] (MAJOR) Whitespace changes are idempotent and grammar-aware: minify removes only whitespace the known grammar makes insignificant, token lists keep author whitespace collapsed to one space, pretty printing adds none inside unknown syntax (`Printer::delim`), and the PR reports the real-world size delta (#1141 grew one space per pass; #980; size regressions [open #1378] and #1151 from 32f1f52).
  verify: R2; S2 on the realworld lane (daisyui, basecoat and tailwind-preflight carry Tailwind output); probes custom-properties/var-empty-fallback-idempotent-2, custom-properties/attr-type-syntax-print.
- [PRINT-05] (MAJOR) Omitting default components never yields an empty or different value: an all-default shorthand prints a keyword, separators stay right with each component omitted, and zero checks use `is_zero()` rather than equality with a px zero (master FAILS [open #1146]: `border-image:none` -> `border-image:`, PR #1336; [open #981]: a `0rem` spread is printed, src/properties/text.rs:1438-1445).
  verify: probes border-outline/border-image-none-serializes-empty, border-outline/border-image-none-not-empty-2; O3 (engines reject the empty value); O7 `valid-became-invalid`.
- [PRINT-06] (BLOCKER) Every name that reaches output goes through `serialize_identifier`, `serialize_name` or `write_ident`: property ids, at-rule names, unknown descriptors, `@page` names, custom pseudo-classes, media types, layer and keyframes names (master FAILS EM-04: raw `write_str` at src/properties/mod.rs:263-266, src/rules/unknown.rs:40, src/rules/font_face.rs:570-572, src/rules/page.rs:290, src/selector.rs:866-870 and :1305, src/media_query.rs:443, so `fake\7d name` closes the block; fixed history #383 layer names, 3bdefdc #125).
  verify: probes printer-serialization/transition-property-ident-escaped, at-rules-other/unknown-at-rule-name-escaped, at-rules-other/font-face-unknown-descriptor-escaped, selectors/custom-pseudo-class-name-escaped, media-queries/custom-media-type-name-escaped, printer-serialization/custom-property-name-escape.
- [PRINT-07] (MAJOR) A number formatting change keeps exactly one `-`, keeps integral values exact (no i32 saturation, no lost type flag that turns `1.0` into a valid `<integer>`), and is applied to every sibling serializer: `CSSNumber::to_css` src/values/number.rs:122-142, `serialize_dimension` src/values/length.rs:513-542, `Percentage::to_css` src/values/percentage.rs:51-75 (regressions #899, #1097, #1200; [open #1219]; see NUM-01, NUM-04).
  verify: probes values-numeric/negative-scientific-percentage-no-double-hyphen, values-numeric/large-integral-value-no-i32-saturation, printer-serialization/token-number-type-flag-kept.
- [PRINT-08] (MAJOR) Strings and `url()` serialize per CSSOM: `"` quotes with `"` and `\` escaped, control characters as code points, a space after a hex escape whenever the next character is a hex digit or whitespace, the chosen quote escaped when quotes are flipped, and unquoted urls escaping whitespace, quotes and parens (INV-SYN-007/009; open PR #1025 loses the space in `"\1 Z"`; #938; open PR #1338 picks the shorter quote).
  verify: probes printer-serialization/hex-escape-before-space, printer-serialization/string-escapes-roundtrip; test_quoting_unquoting_urls tuples (T4).
- [PRINT-09] (MAJOR) A shortened or rewritten form is accepted by every target browser, not only valid per spec (OM#serialize-a-css-value: no less backwards-compatible form): `image-set()` keeps `1x` (#264), `format("woff")` stays quoted (34de9db), `dppx` where `x` is unsupported, string animation names only where supported (6e47cdb), media `aspect-ratio:1/1` ([open #379]).
  verify: O3 in engine-legacy-2023 and engine-legacy-2021; mutation retarget-legacy; BCD for the emitted syntax.
- [PRINT-10] (MAJOR) The printer context reaches every nested serializer: `ToCss` writes to `dest`, never to a throw-away `Printer` (which loses targets, css_module, vendor_prefix and source-map state, #1145), and print-time lowering (nesting, media range, `#rrggbbaa`, `clamp()`, `light-dark()`, `x`) sees the same targets as minify.
  verify: grep the diff for `Printer::new(`; mutations retarget-none, retarget-legacy (print-time lowering differs when PrinterOptions lack targets); css_modules tests.
- [PRINT-11] (MAJOR) Inline-HTML and encoding safety is unchanged or improved: no `</style` is produced from an escape (master FAILS EM-05), non-ASCII output stays UTF-8 with no `@charset` emitted (by design, #310/#993), and a leading BOM never moves into a selector ([open #338]).
  verify: probe printer-serialization/style-end-tag-not-emitted-in-strings; output-not-contains probes; `lcr show` on the output bytes.
- [PRINT-12] (MAJOR) Deep nesting overflows neither printer state nor the stack: indentation is a `u8` (src/printer.rs:76) and `StyleRule::to_css`/`CssRuleList::to_css` recurse without a limit ([open #1155]; EM-11: indentation grows 2 per level and wraps past 127, so 150 levels print with 44 spaces in release builds; debug builds, such as the harness adapter, panic with `attempt to add with overflow`).

- [PRINT-13] (MINOR) Hot paths stay lean: `write_str`/`write_char` gain no per-call work (#971 moved newline tracking into `write_str_with_newlines`), and source-map columns stay consistent (columns are bytes; open PR #1354).

  verify: test_license_comments tuples; probe printer-serialization/comment-dimension-function.
- [PRINT-15] (MINOR) No output churn without a semantic reason: case-only keyword changes (`currentColor` -> `currentcolor`, closed #953), quote style and ordering changes are avoided because downstream snapshot suites diff output (Tailwind), and integrator contracts hold: dependency placeholders print as `url("…")` (Vite string-replaces them), urls stay quoted when not minifying (#160, Parcel).
  verify: S1 and realworld deltas; node/test dependency tests (B5).

  verify: compare the PR's tests (`test` helper = minify + pretty printer) with probes in mode print; `lcr show`.
