# visitor-api checklist (VISIT)

Covers the Rust and JS visitor APIs and custom at-rules: `src/visitor.rs` (Visitor trait, VisitTypes), `derive/src/visit.rs` (`derive(Visit)`, `skip_visit`, `visit(...)`, `visit_types`), the JS bridge `napi/src/transformer.rs` (serde round trip through serde-content), `napi/src/at_rule_parser.rs` (customAtRules), `node/composeVisitors.js`, and `wrap()` in node/index.js and wasm/.
Top failure modes: (1) the JS round trip rejects or alters returned nodes (`null` vs None, #1065/#1081 since #1062 in v1.30.2; large numbers #1188; `Ignored` rules #1104; `serde(skip)` state #951; selector flags #1079); (2) coverage holes (fields not visited #1205, hooks not composed #875, `visit_rule` overrides #1206); (3) phase assumptions (visitors run before `minify()`, `var()` values stay token lists, token whitespace #976).
config/areas.json maps `napi/*` and `node/*` to bindings-api only: use this list for visitor changes there too.

- [VISIT-01] (BLOCKER) An identity JS visitor is a no-op: with every hook returning its input, output is byte-identical for the PR's inputs and real-world CSS, including `null` Option fields (`var()` without fallback, anonymous `@layer`), numbers outside -32768..65535, ±infinity and -0, bundler `Ignored` rules, and selectors with pseudo-elements (deserialized selectors get no recomputed flags, selectors/serialization.rs:687-701).
  verify: node test with an identity visitor for each hook the PR touches, over tests/testdata and realworld files (PR #1357's round trip is a model); B5 (#1065 #1081 #1188 #1104 #1079; `coerce_numbers` in napi/src/transformer.rs:759-831).
- [VISIT-02] (MAJOR) Visitor errors become JS errors in every entry point: `transform` maps them (`map_err(CompileError::JsError)`, napi/src/lib.rs:752), but `transformStyleAttribute` calls `attr.visit(visitor).unwrap()` (:1010), which panics, and aborts in release builds, when a visitor throws or a returned node fails to deserialize (read at cbeaf83, not executed: UNVERIFIED); new entry points add no such unwrap.
  verify: node test whose `transformStyleAttribute` visitor throws; risk flag `added-unwrap` on napi/.
- [VISIT-03] (MAJOR) State in `#[serde(skip)]` fields of a visitable type survives a JS round trip or is documented as lost: `StyleSheet.options` (the custom-media flag, css_modules) and `content_hashes` reset to Default when a `StyleSheet`/`StyleSheetExit` hook returns the sheet (src/stylesheet.rs:86-90, #951 open).
  verify: node tests `StyleSheetExit: s => s` with `drafts.customMedia` plus targets, and with cssModules; grep the diff for `serde(skip)`.
- [VISIT-04] (MAJOR) New AST types and fields are visitable as intended: `cfg_attr(feature = "visitor", derive(Visit))` on new types, `skip_visit` only where a field must stay invisible (a URL stored as `CowArcStr`, like the `@import` url at src/rules/import.rs:25-36, is invisible to Url visitors, #1205), `visit(visit_x, TYPES)` for a new visitable kind, and `VisitTypes` bits (src/visitor.rs:96-134) extended without renumbering.
  verify: GEN-24; a Rust test with a visitor that counts the new node (examples/custom_at_rule.rs builds with `visitor` under B1).
- [VISIT-05] (MAJOR) JS hooks stay complete: a new visitable kind or rule gets its napi dispatch (napi/src/transformer.rs; rule names at :295-318), a `composeVisitors` entry (node/composeVisitors.js:24-52), `Visitor` types in node/index.d.ts and wasm parity, and `composeVisitors` forwards StyleSheet, StyleSheetExit and `Rule.custom.*` (#875).
  verify: composeVisitors.test.mjs with two visitors on the new hook; B5; `TEST_WASM=node|browser` runs only in CI test-wasm (B6).
- [VISIT-06] (MAJOR) The phase contract is unchanged or declared breaking: visitors run after parsing and before `minify()` (napi/src/lib.rs:752 then :761; bundles :887 then :896; style attributes :1010 then :1019), so they see unmerged rules, unlowered nesting and media, and `@custom-media`; `var()`/`env()` values stay `Property::Unparsed` and are not re-typed after token edits unless the visitor returns `{property, raw}` (#385).
  verify: read the napi/src/lib.rs call order; node tests "design tokens", "env function" and raw values (#893 #943 #459 #554).
- [VISIT-07] (MAJOR) Rules and blocks returned by visitors go through the normal pipeline with the meaning parsed input would have: interleaved declarations and nested rules keep their order (nested declarations since 6c465c1, #964), and a relative nested selector spliced into a style rule gets its implicit `&` (top-level `@mixin` bodies parse with `is_in_style_rule = false`, napi/src/at_rule_parser.rs:116 → src/parser.rs:1176, #1071 open).
  verify: customAtRules.mjs "mixin" and "style block" cases with a nested rule without `&`, both lowered (chrome 95) and preserved.
- [VISIT-08] (MAJOR) Token-list edits print correctly: author whitespace tokens are kept (collapsed to one space since 32f1f52), replaced `var()`, `env()` and function tokens neither glue to their neighbors nor lose required spaces, and `var(--x, )` stays idempotent.
  verify: visitor.test.mjs Token, Function and Variable tests; probe custom-properties/var-empty-fallback-idempotent-2; R2 (#976 #1001 #1005 #1141/#1142, PR #1029).
- [VISIT-09] (MAJOR) Serializers that omit default components compare semantically, so visitor-produced values print validly: zero checks are value tests, not `== NonNegative::zero()` or `Px(0)` comparisons (text-shadow prints a `0rem` spread, src/properties/text.rs:1438-1445, #981; same pattern at box_shadow.rs:115-119 and effects.rs:127, :290).
  verify: node test with a px→rem Length visitor on the touched property; grep the diff for structural zero comparisons.
- [VISIT-10] (MAJOR) Custom at-rules keep their contract: prelude syntax strings follow the `@property` syntax grammar (one type with `|`, `+`, `#`, or `*` for raw tokens, #881), body kinds are declaration-list, rule-list or style-block, `is_nested` is passed (c7913b0), built-in at-rule names keep precedence (#1171), and statement rules print their `;` (napi/src/at_rule_parser.rs:166-197 writes none when the body is None; unfiled).
  verify: customAtRules.mjs (7 tests); compact output plus a strict re-parse with a statement custom at-rule followed by a rule.
- [VISIT-11] (MAJOR) Rust `Visitor` API changes are source-compatible or declared: required methods, signatures, the `Error` associated type (#406), `visit_types()` (#574), and default recursion (`visit_rule` calls `visit_children`, src/visitor.rs:169-171; overriding it without that call skips children, #1206).
  verify: read the src/visitor.rs diff; examples/custom_at_rule.rs and tests/test_custom_parser.rs build and pass under B1.
- [VISIT-12] (MINOR) The visitor-function form and `addDependency` (#1170) work across repeated calls: `wrap()` assigns `options.visitor = options.visitor({...})` on the caller's object (node/index.js:33-39), so reusing one options object loses the factory; wasm/index.mjs and composeVisitors behave the same way.
  verify: node test calling `transform` twice with the same options object and a function visitor; diff wasm/index.mjs against node/index.js.
- [VISIT-13] (MINOR) Visitors cost only for what they visit: `visit_types()` still skips unvisited subtrees and JS crossings happen per matched node (visitors are about 2x slower than none, #363).
  verify: read the VisitTypes computation in napi/src/transformer.rs; node timing on a large file with one hook.
